Claude:
I'll rework it to generate one row per death, with year, cause, age group, and gender sampled from plausible distributions.The main structural change: your original script had a fixed population of 151 units (divisions) and sampled attributes for each. Here the unit is a death, so the row count is driven by how many deaths occur per year rather than being fixed up front.

A few specifics worth flagging:

**Year handling.** Rather than sampling years, I set counts per year in `deaths_per_year` and used `np.repeat`. That way each year has a deliberate number of records, which matters if you later want to look at trends — sampling years with probabilities would make annual totals noisy for no good reason. Swap in the real counts if you have them.

**Probabilities.** The cause weights are heavily loaded toward acute drug toxicity (0.57), with male at 0.80 and 40-59 as the modal age group. These are rough approximations of the published Toronto Public Health pattern, not fitted values — adjust them to whatever you want your simulation to assume.

**Independence.** Cause, age group, and gender are sampled independently, which is the simple case but is wrong in a way you may care about: drug toxicity skews young, cardiovascular disease skews old. If your analysis is going to test for those associations, the simulated data won't have them. The fix is to sample age group conditional on cause — a dict of `{cause: probability vector}` and a per-row `np.random.choice`, or a vectorized version using per-cause masks.

**Directory creation.** Added `Path(...).mkdir(parents=True, exist_ok=True)` since `write_csv` won't create the folder and fails otherwise.

from pathlib import Path

import numpy as np
import polars as pl

np.random.seed(853)


#### Simulate data ####

# Years covered by the simulated data
years = [2022, 2023, 2024]

# Number of deaths recorded in each year
deaths_per_year = {2022: 187, 2023: 261, 2024: 236}

# Cause of death categories
causes = [
    "Acute Drug Toxicity",
    "Cardiovascular Disease",
    "Homicide",
    "Other Diseases",
    "Pending",
    "Suicide",
    "Unintentional Injury",
    "Unknown",
]

# Age groups
age_groups = ["<20", "20-39", "40-59", "60+", "Unknown"]

# Genders
genders = ["Female", "Male", "Unknown"]

# Probabilities for cause, age group, and gender distribution
cause_probs = [0.57, 0.10, 0.02, 0.11, 0.06, 0.04, 0.03, 0.07]
age_group_probs = [0.01, 0.30, 0.45, 0.20, 0.04]
gender_probs = [0.19, 0.80, 0.01]

# Generate the data using numpy and polars
n_deaths = sum(deaths_per_year.values())

years_sampled = np.repeat(years, [deaths_per_year[year] for year in years])
causes_sampled = np.random.choice(causes, size=n_deaths, replace=True, p=cause_probs)
age_groups_sampled = np.random.choice(
    age_groups, size=n_deaths, replace=True, p=age_group_probs
)
genders_sampled = np.random.choice(
    genders, size=n_deaths, replace=True, p=gender_probs
)

# Create a polars DataFrame
analysis_data = pl.DataFrame(
    {
        "death_id": [f"Death {i}" for i in range(1, n_deaths + 1)],
        "year": years_sampled,
        "cause_of_death": causes_sampled,
        "age_group": age_groups_sampled,
        "gender": genders_sampled,
    }
)


#### Save data ####
Path("data/00-simulated_data").mkdir(parents=True, exist_ok=True)
analysis_data.write_csv("data/00-simulated_data/simulated_data.csv")

That error is coming from `show_package()`, not from the download itself. This dataset has two civic issues (affordable housing, poverty reduction) but three topics and three formats, and `show_package()` tries to put all of those into a single one-row tibble — columns of length 2 and 3 can't be recycled together. It's a limitation of the package's metadata handling, and it'll fail on this dataset no matter what you do.

The good news: `show_package()` is purely informational. Dropping it changes nothing about the download.`list_package_resources()` won't hit the same problem — it builds its tibble from the resource list (name, id, format, last_modified), where every column has one value per resource, so there's nothing to recycle.

If you do want the package-level metadata for your paper's data section, two options that sidestep the bug:

- `browse_package("8546b6d9-41ec-48df-895f-09e86784ef26")` opens the portal page in your browser.
